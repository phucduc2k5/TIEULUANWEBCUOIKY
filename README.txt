1. CẤU TRÚC
- index.html: Trang chủ
- about.html: Giới thiệu cá nhân
- hobbies.html: Sở thích bóng chuyền
- contact.html: Thông tin liên hệ và biểu mẫu minh họa
- css/style.css: Giao diện và responsive
- js/script.js: Menu di động, năm hiện tại, kiểm tra biểu mẫu
- images/: Ảnh đại diện và minh họa bóng chuyền

2. CÁCH MỞ WEBSITE
Giải nén ZIP, mở thư mục my-portfolio, nhấp đúp index.html.
Có thể dùng Visual Studio Code và tiện ích Live Server để chạy thử.

3. TRIỂN KHAI GITHUB PAGES
- Tạo hoặc mở repository GitHub.
- Tải toàn bộ nội dung bên trong thư mục my-portfolio lên thư mục gốc repository.
- Đảm bảo index.html nằm ngay thư mục gốc.
- Vào Settings > Pages.
- Chọn Deploy from a branch, Branch: main, Folder: /(root), rồi Save.
- Chờ GitHub Pages triển khai và mở URL được cung cấp.

4. LƯU Ý CHỨC NĂNG
Biểu mẫu liên hệ hiện chỉ kiểm tra dữ liệu và hiển thị thông báo tại trình duyệt. Website chưa kết nối máy chủ hoặc dịch vụ nhận tin nhắn, do đó không gửi email thực tế.

5. BÁO CÁO
File Word tiểu luận được đặt ở thư mục gốc của gói ZIP. Các hình trong báo cáo là minh họa bố cục; hãy thay bằng ảnh chụp màn hình website chạy thực tế nếu giảng viên yêu cầu minh chứng.
